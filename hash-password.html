Password Hasher

Generate a secure SHA-256 hash of a password to store in your Google Sheet. The real password is never saved anywhere.

SHA-256 Hash — paste this into your Google Sheet
How to use:
1. Type the username and password above, click Generate Hash
2. Copy the hash value
3. Open your RCCG Media Users sheet ↗
4. In the Password column, paste the hash instead of the plain password
5. The site will automatically recognise it as a hash

To add a new user: add a new row with their username and their hashed password.
To change a password: generate a new hash and replace the old one in the sheet.
⚠ This tool runs entirely in your browser — nothing is sent to any server. Close this tab when done. Do not share this page with general users.
